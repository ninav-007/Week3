🌦️ Mini Project – Weather App (Console Version)
🔹 Project Description

A simple weather application that fetches live weather data from a public API and displays:

Temperature

Wind speed

🔹 Features

Uses async/await for async flow

Handles errors using try-catch

Displays output using template literals

Clean and readable logic
